# Further progress and lifetime review

Twelve additional source files were read around loop progress, retained collections and their production callers. The accompanying JSON records source hashes and exact loop lines. These are targeted source reviews, not an incident replay or a claim that the whole candidate list has been manually cleared.

| File                                                          | Progress and ownership evidence                                                                                                                                                                                                                                                          | Remaining limit                                                                                                                                                          |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/shared/hermes-session-run-index.ts`                      | Exact-key cursors advance; binary search shrinks its interval. Union-find links consumed positions to strictly earlier positions, with zero as the terminal sentinel; compression does not add entries. Main and relay callers build one index per merge from the supplied session rows. | Arrays/maps scale with input row count.                                                                                                                                  |
| `src/shared/foreground-process-selection.ts`                  | Each ancestor step tests a per-walk visited set before following `ppid`; missing/cyclic ancestry returns false. Memoized answers belong to one captured process-table snapshot.                                                                                                          | Snapshot and recognized-candidate collections scale with the process table.                                                                                              |

Main and relay production constructors use a positive 1,000 ms delay, so rescheduling moves the deadline beyond that flush's captured time. The separately reviewed loose-ref walker pops pending directories, checks cancellation and a 4,096-directory ceiling between listings, and stops at its file budget. A single `readdir` still allocates the entire directory and can append more than 4,096 child paths before the next ceiling check. That is input-sized transient allocation, not a demonstrated repeated-retention leak or a whole-process memory bound.
